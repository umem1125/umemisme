Halo gais! Kenalin, nama gue Umam. 👋

Mungkin keliatan agak random, tapi gue adalah lulusan S1 Sastra Inggris yang akhirnya nyemplung dan beralih profesi ke dunia IT. Sekarang, gue fokus berkarir sebagai **Software / Web Developer**, khususnya di bidang *frontend development*. 

Meskipun background kuliah gue beda jauh sama dunia perkodingan, tapi ketertarikan gue buat ngulik teknologi baru bikin gue betah banget di industri ini. 

---

## Yang Biasa Gue Kulik (Keahlian) 💻

Selama berkecimpung di dunia web dev, ini beberapa tech stack dan area yang sering gue pegang:

* **Frontend Magic:** HTML, CSS, JavaScript (ES6+), dan React.
* **Modern Frameworks:** Astro (buat bikin web statis super kenceng kayak web ini) dan Next.js.
* **Styling Tools:** Tailwind CSS biar styling cepet dan anti ribet.
* **Version Control:** Git & GitHub buat kolaborasi kodingan biar gak berantakan.

Gue selalu percaya kalau ilmu itu dinamis. Latar belakang pendidikan bukan halangan buat belajar hal baru, makanya gue selalu berusaha buat *update* skill gue biar makin *better* hari demi hari.
